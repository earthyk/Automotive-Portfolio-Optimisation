SLIDE 5 — DATA PREPARATION AND CONDITIONAL MEDIAN IMPUTATION
================================================================================

COMPONENT 1 — SLIDE TITLE AND VISUAL ANCHOR RECOMMENDATION
-----------------------------------------------------------
Title (as displayed on slide):
"Iterative Conditional Median Profiling: Preserving Intra-Brand Variance"

Visual Anchor: A two-panel annotated diagram. The left panel is a stylised
grouped-bar chart with six manufacturer groups on the x-axis (toyota, honda,
bmw, volkswagen, mazda, subaru) and "normalized-losses" on the y-axis. Each
bar group shows the brand-conditional median as a solid coloured horizontal
reference line and the global fallback median as a dashed black horizontal
line across all bars. Missing value cell locations are indicated by hollow
bars with a red "NaN" label inside, and the filled imputed values are shown
as solid bars with a green upward arrow. The right panel displays the formal
two-branch piecewise equation (matching Equation 1 of the paper) typeset
in clean sans-serif mathematical notation, with each branch colour-coded to
match the left panel: blue for brand-conditional median, red for global
fallback. A caption below the right panel reads: "Tier 1 applied for 12 of
18 missing cells. Tier 2 global fallback invoked for 0 cells (all brands
had non-null representatives in this dataset)."

COMPONENT 2 — CORE SLIDE ASSERTIONS
-------------------------------------
• Brand-conditional imputation preserves manufacturer-level variance structure,
  preventing artificial convergence toward a single global mean.
• The global fallback tier guarantees zero residual NaN values even when entire
  manufacturer groups contain no valid observations for a column.
• All 18 missing values across normalized-losses, bore, and stroke were resolved
  exclusively via the brand-conditional tier in this dataset.

COMPONENT 3 — VERBATIM PRESENTER SCRIPT
-----------------------------------------
"Missing value imputation is a methodologically consequential decision in any
portfolio analysis. A naive global mean substitution would artificially collapse
inter-brand variance, distorting correlation coefficients downstream. Our
Iterative Conditional Median Profiling strategy, formalised in the piecewise
equation displayed on the right panel, addresses this by first computing the
brand-specific conditional median within each manufacturer group and using that
as the primary fill value. Only when an entire manufacturer group is null — which
did not occur in this dataset — does the algorithm fall back to the global median.
The left panel visualises this process: each manufacturer's missing cells receive
that brand's own median, preserving the distributional character of the raw data."
